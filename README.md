匿名实时留言板
一款极简、轻量、无广告的匿名实时留言板系统，基于原生前端 + WebSocket 实现实时留言与回复互动。界面干净轻量化，适配移动端与电脑端。
📌 项目说明
本仓库仅为前端开源代码。
因后端搭建、配置流程较为复杂，后端完整源码、环境配置、部署教程已全部整理至个人博客。
仅部署本前端代码可正常展示页面，留言、实时同步、图片上传等功能需要搭配后端服务使用。
👉 后端源码 & 完整部署教程：请查看我的个人博客（自行替换为你的博客链接）
✨ 核心功能
- 匿名访客系统：首次访问自动生成随机访客昵称，Cookie 持久化留存
- 实时留言互动：基于 WebSocket 实现毫秒级实时推送，无需刷新页面
- 楼中楼回复：支持对单条留言、单条回复二次回复，层级清晰
- 回复折叠/展开：多条回复自动折叠，按需展开，页面更整洁
- 图片上传预览：支持 JPG/PNG/GIF/WEBP 图片上传、超大图压缩校验、点击放大预览
- 智能链接解析：自动识别文本网址，转为可点击跳转链接
- 消息通知系统：铃铛通知、未读角标、通知列表、全部已读/清空通知
- 通知详情弹窗：点击通知自动打开详情弹窗，精准定位对应留言与回复
- 分页加载优化：历史留言点击加载更多，无数据后自动切换为「回到顶部」
- 断线自动重连：WebSocket 心跳保活、断网自动重连，稳定性强
- 全端自适应：适配手机、平板、电脑端，界面简洁舒适

📁 项目结构
本仓库仅包含前端静态资源：
- index.html：主页面结构、样式、布局
- main.js：全部交互、分页、WebSocket、通知、上传核心逻辑
🚀 前端部署教程（GitHub Pages）
本项目为纯静态前端项目，部署零依赖、零配置。
1. Fork / 下载本仓库代码
2. 上传至自己的 GitHub 仓库
3. 开启仓库 Pages 服务，选择 main 分支、根目录部署
4. 等待 1-2 分钟即可在线访问
如需对接自己的后端，可自行修改 JS 内的接口地址与 WebSocket 地址。
